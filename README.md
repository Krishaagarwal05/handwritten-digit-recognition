# Handwritten Digit Recognition

## About the Project
This project recognizes handwritten digits (0–9) using a neural network trained on the MNIST dataset.

## Technologies Used
- Python
- TensorFlow and Keras
- NumPy
- Matplotlib

## Features
- Trains a neural network to classify handwritten digits.
- Predicts digits from image data.
- Saves the trained model for future predictions.

## How to Run
1. Install Python.
2. Install the required libraries:
   ```bash
   pip install tensorflow numpy matplotlib
   ```
3. Run the Python file:
   ```bash
   python first.py
   ```

## Project Purpose
This project was developed to learn machine learning, neural networks, and image classification.
